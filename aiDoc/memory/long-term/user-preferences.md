# 用户长期偏好

## 语言与表达

- 默认使用中文沟通和书写项目级 AI 文档

## 文档组织偏好

- 不希望在多个工具目录中重复维护同一份 project rule
- 更倾向于 `AGENT.MD + aiDoc/` 的单一真源结构
- 更偏好 harness engineering 风格的分层文档设计
- 更偏好“讲解型示例”，而不是纯模板式示例

## 记忆管理偏好

- 不仅要保留长期记忆，也要记录每次用户提出的业务需求
- 业务记忆应独立存放，不能混入长期偏好

## 生产服务器资源

- 用户于 2026-11-20 明确要求：4 GB 生产机禁止并行重构建，必须保护 MySQL 等线上服务与终端登录。
- 曾因 swag init 和 Vite 构建并行造成约 90% 内存使用，登录通道卡挂约 1 小时；不得重复此调度方式。
- Go、Node、开发预览和浏览器回归共用资源锁，单任务 640 MiB 硬上限，保留至少 1 GiB 可用内存；低于余量时停止自身任务。
- 不在生产机执行全量 swag init，不绕过检查或擅自提高限制。
